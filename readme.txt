== Description ==

A cheerful block theme for gelato and ice cream shops. Patterns for today's flavour and the week's rotation, the full menu by category, a menu board, several locations with their own hours, your story, a photo gallery and event catering, all editable in the Site Editor.

Double Scoop Lite is a block theme: every page, header and footer is edited in the Site Editor, with no page builder. The front page is built from patterns you can rearrange, and each section is also in the pattern inserter for any page.

A contact form is plugin territory: for a form on your contact page, install a form plugin from WordPress.org.

The full version of Double Scoop adds a one-click demo import (pages, menu, photos and journal posts), a WooCommerce shop set up with products and photos, a dark style and a setup guide: https://checkout.freemius.com/theme/43052/plan/74944/

== Frequently Asked Questions ==

= Does the theme collect any data? =

No. Double Scoop Lite sets no cookies and uses no tracking. To offer updates it asks GitHub (api.github.com) for the latest release of github.com/allanninal/double-scoop-lite, at most twice a day; that request carries nothing about your site. The upgrade notice in the dashboard is a plain link; dismissing it is stored on your own site.

= How do I update it? =

Like any theme: new versions appear under Dashboard › Updates. Each version is also a release at https://github.com/allanninal/double-scoop-lite/releases, with the theme zip attached. Install that zip, not GitHub's "Source code" download, whose folder name is different.
